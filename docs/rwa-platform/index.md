# RWA Platform

The TBook RWA Platform lets fintechs and corporates offer **tokenized real-world-asset products** — stablecoin yield, tokenized gold — to their users, or invest their own treasury, through **one REST API plus webhooks**. It is non-custodial by design: every money movement is an unsigned transaction that the API builds and **your** wallet infrastructure signs; TBook never holds funds or keys.

It is a standalone service with its own developer documentation:
